# MK Telnet
Prosty klient Telnet dla iPhone i dekoderów Enigma2. Obsługa IP, portu 23, loginu/hasła i poleceń terminalowych. Wymaga iOS 16+.

Nie ma reklam i subskrypcji. Hasło nie jest zapisywane. Telnet przesyła dane **bez szyfrowania**: używaj wyłącznie w zaufanej sieci lokalnej.

Aby zbudować IPA, otwórz GitHub Actions na gałęzi mk-telnet-ios i pobierz artefakt MKTelnet-unsigned-ipa. SideStore podpisuje IPA podczas instalowania.
