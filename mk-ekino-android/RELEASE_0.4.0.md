# MK Kino 0.4.0 — źródła

[Archiwum kodu źródłowego](packages/MK_Kino_Android_TV_0.4.0_SOURCE.zip)

Nowy wygląd MK Kino: boczne menu, duże okładki w poziomych rzędach, półprzezroczyste panele i turkusowe zaznaczenie. Filtry i podgląd opisu są pod ręką. Odświeżony odtwarzacz: duże przyciski, nowy pasek postępu i przewijanie pilotem z przyspieszaniem przy przytrzymaniu.

Walidacja: 34 testy logiki, kompilacja względem Android API 35 i sprawdzenie interfejsów odtwarzacza. Testy pobierania potwierdziły filmy i seriale z obu katalogów. Nawigację nowego interfejsu należy jeszcze sprawdzić pilotem na fizycznym Android TV.

Instrukcja budowania i licencja znajdują się w archiwum. Klucz podpisujący jest przechowywany osobno i nie jest publikowany.
